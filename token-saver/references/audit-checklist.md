# צ'ק-ליסט ביקורת

ביקורת חד-פעמית: איפה הטוקנים דולפים ומה לתקן קודם. הרקע לכל פעולה ב-principles.md.

## צעד 0: סביבה
- Claude Code (גישה ל-bash וקבצים): בצע את כל הצעדים.
- claude.ai (בלי גישה לקבצים): דלג לצעד 4, שאלות בלבד, ואז טבלת פעולות claude.ai שבסוף.

## צעד 1: גודל CLAUDE.md
נטען במלואו בתחילת כל סשן, אף פעם לא מפונה. כל שורה עולה טוקנים כל הסשן.
```
wc -l ~/.claude/CLAUDE.md CLAUDE.md 2>/dev/null
```
- מעל 200 שורות = מנופח. יעד: מתחת ל-200.
- קבצי @import נטענים גם הם בהפעלה; בדוק אותם.
- הערות HTML `<!-- -->` נחתכות מהקונטקסט (חינם).
- בדוק גם MEMORY.md (200 השורות הראשונות נטענות) ו-.claude/rules/ (נטען רק עם קבצים תואמים).

## צעד 2: שרתי MCP
כל שרת מחובר דוחף רשימת כלים וסכמות ל-system prompt, גם בלי שימוש.
```
claude mcp list
jq '.mcpServers | length' .mcp.json 2>/dev/null
jq '.mcpServers | length' ~/.claude.json 2>/dev/null
```
- ספור כמה מוגדרים וכמה באמת בשימוש בסשן הזה.
- כבה לא בשימוש: `/mcp` או `claude mcp disable <name>`.
- טעינת סכמות נדחית כברירת מחדל (ToolSearch); אל תגדיר `ENABLE_TOOL_SEARCH=false`.

## צעד 3: פירוט חי (מריץ המשתמש)
קלוד לא מריץ פקודות סלאש בעצמו. בקש מהמשתמש להריץ ולהדביק:
- `/context` (או `/context all`): מה ממלא את החלון ורמזי אופטימיזציה.
- `/usage` (כינויים `/cost`, `/stats`; `d`/`w` ל-24 שעות מול 7 ימים).
- claude.ai: Settings > Usage.
סמן את הצרכן הכי גדול ותקן אותו קודם.

## צעד 4: שלוש שאלות הרגלים
1. אורך שיחות: מפרידים נושאים ב-/clear (claude.ai: צ'אט חדש) או צ'אט אחד ארוך?
2. מודל ברירת מחדל: Fable/Opus (יקרים) או Sonnet/Haiku?
3. effort: high (ברירת מחדל) גם לשוטף, או low/medium?
ב-claude.ai הוסף: משתמשים ב-Projects לידע חוזר? web search/Research/connectors דלוקים בלי שימוש?
